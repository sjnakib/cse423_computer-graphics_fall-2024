# Assignment 1: Color Interpolation

CSE423 Computer Graphics, Fall 2024, BRAC University.

This is a theory assignment about Gouraud shading and color conversion. The task gives RGB colors at the vertices of a figure. You use Gouraud shading to find the RGB color at points P0 to P7, then convert those RGB values to HSV.

## Files

- `docs/assignment-01.pdf`: the task sheet. It has the figure and the vertex colors.
- `docs/solution.pdf`: my handwritten solution, 4 pages.

## What the task asks

The student ID gives four numbers A, B, C, and D. They are the first, second, third, and fourth pairs of digits from the left. The vertex colors are built from these numbers. The solution interpolates the colors across the figure and converts the result to HSV.
